## V02 메쉬 입력 (G2 추가 항목 — 시도, 정직 보고)

- 방법: 해석 O-grid all-hex 메쉬 (nθ=64, nr=6, z 2층, 384 hex, 구멍 경계 정확)
  → `outer_faces()` → `trimmed.build_trimmed_table` (q=4) → `run_linear`
  (G1 `v02_roark.py`와 동일 spec, finest (80,16,4)).
- 경계 면적 자가검증: 측정 15900.2 vs 해석 15914.7 (구멍 차감 + 64각벽 + 모서리 현), 0.5% 이내.
- 결과 (finest (80,16,4), 671 s): peak 1.89e-06, cut 3091, fb 48.
  Coreform 기준값(4.3175e-6) 대비 오차로만 판정한다. 메쉬 경로의 일관성은
  동일 spec의 CAD-path 실행과 같은 trimmed machinery를 공유한다는 점에서
  판단한다 (fb 수, 셀 분류 일치).
  Roark 게이트 오차 56.2% → 1% 게이트 미달 (extension 부재 + 64각형 facet 근사).
  fb=48은 fallback 카운트일 뿐 CAD-path와의 일치가 아니다.
- 128각/nr=8 variant (`test_v02_mesh_input_peak_fine`, 749 s): peak 1.95e-06
  (cut 3068, fb 48) — 64각(1.89e-06)과 3% 일치, CAD-path와는 41% 차이 유지.
  → 차이는 분해능이 아니라 facet 평면 자체 (평탄 facet crown은 곡률 1/10을
  잃어 Kt를 과소평가). 메쉬 경로는 일관되게 동작, Roark 게이트는 extension +
  곡면 형상 입력이 필요. G2 추가 항목 시도 완료 (미달, 정직 보고).
