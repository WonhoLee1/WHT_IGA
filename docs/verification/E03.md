  3. **환형 RBE3 분포 결합 효과**: `||W_op u_surf|| <= 8.97e-17`로 장착면 합력·모멘트 구속(강체 운동 6모드 제거)을 기계 정밀도로 만족하면서, 장착면 자체의 반경 방향 열수축(`mount_ctrl_max_yz = 0.118..0.214 mm`)을 허용해 면 전체 고정(pinned) 시 발생하는 인위적 장착부 응력·소성 과대평가([glass-to-metal-seal.md](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/research-cf-IGA/user-guide/example-problems/glass-to-metal-seal/glass-to-metal-seal.md) §2.6.2)를 억제합니다.
