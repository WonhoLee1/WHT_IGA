## 1. 입력 요약

- 기하 형상: `[-5, 5] x [-5, 5] x [0, 100]` ($b = 10$, $L = 100$) 외팔보
- 재료 물성: 전 영역 동일 등방 선형탄성 $E = 1.0 \times 10^{11}$, $\nu = 0.3$ (내부 경계는 연속체 역학적으로 비가시적이며 셀 도메인 분리의 불변성을 검증)
- 이산화 (`degree=2`):
  - **Monolithic 모델**: 단일 `BoxSpline (2, 2, 7)` 도메인
  - **7-박스 분할 모델**: 동일 `BoxSpline (2, 2, 7)` 격자 위에 축방향 7개 구간(`k = 0..6`)별로 [`CellDomainSpec`](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/kratos_backend/assembly_builder.py) (`box_0` ~ `box_6`, 각각 개별 `Properties` ID 할당)을 부여하여 다중 셀 공유 B-spline 필드 구성
- 경계조건 및 하중: $z = 0$ 고정단 전 변위 구속, $z = 100$ 자유단 전단 트랙션 $t_y = -0.01$ (합력 $P = 1.0$), [`solve_hybrid_iga_fe`](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/kratos_backend/native_fe.py) (`use_pardiso=True`)
