### 6.2 알려진 한계 및 범위 밖 항목

1. **`p_max` 과대 예측**: 표면 삼각형 Gauss 점 penalty 정식화에서는 활성 Gauss 점 이산 간극에 하중이 집중되어 국소 `p_max`가 Hertz $p_0$ 대비 크게 나타난다(`h=0.125` R1 `+59.82 %`, `h=0.25` R2 RMS `213.32 %`). `v08.json` 명세상 `p_max`는 기록·비교 전용이며 게이트 비대상이다.
2. **유령 셀 비선형 반력(`eq_cut_T = 1.30 %`)**: 대변위 미끄럼($t = 0.70, u_x = 2.833\text{ in}$)에서 `OUT` 유령 셀이 `TotalLagrangianElement3D4N`을 사용함에 따라 절단면 반력과 계면 마찰력 간 1.3% 편차가 발생한다(`ghost_alpha = 0` 또는 유령 셀 소변형/강체 이동 처리는 향후 개선 과제).
3. **미실행 영역**: `h=0.125` R2 NLGEOM 전체 이력(수 시간 예상)과 `0.70 < t ≤ 1.0` 블록 우측 모서리 접근 구간(`v08.json` 반무한체 비교 창 제외 구간)은 본 검증에서 실행하지 않았다.
