## 정식화

- 1/4 모델 `10 × 10 × 0.25 mm`, 대칭 `u_x(x=0) = 0`, `u_y(y=0) = 0`, 반경 `1 mm` 핫스팟(영역 1)에 등방 열변형률 `1e-3`, 바깥 영역 2는 `0`. 두 영역의 `E = 1e5 MPa`, `ν = 0.3`이 같다.
- **이중 시행 필드 + 대칭 Nitsche + 영역별 AgFEM (`wht_iga/analyses/bimaterial.py::solve_bimaterial_thermal_stress`)**:
  - 영역 1($r \le 1$)과 영역 2($r \ge 1$)의 강성 행렬 `K₁, K₂`를 각각 **Kratos `SmallDisplacementElement3D4N`**(QP 요소)으로 독립 조립한다 (평면응력 변환 `plane_stress_as_plane_strain` 적용, `q = min(2p, 4) = 2`).
  - 계면 호($r = 1$) 위에서 대칭 Nitsche 일관항·점프 벌칙항(Annavarapu 체적분율 가중치 $\kappa_1 = \frac{\eta_1/E_1}{\eta_1/E_1 + \eta_2/E_2}, \kappa_2 = 1 - \kappa_1$, $C_\gamma = 10p^2$)으로 변위 연속성과 열응력 점프(`σ* = D ε*`)를 자연스럽게 결합한다.
  - 영역별로 독립된 AgFEM 연장(`per_region_extension`, `θ = 0.2`)을 적용해 미세 절단 셀($\eta \to 10^{-6}$)에서도 균일한 강제성과 유계 조건수를 유지한다 (`test_p4_bimaterial.py` 검증).
- 해석해 (무한판 원형 개재물, 평면응력): 내부 $\sigma = -E\varepsilon/2 = -50\text{ MPa}$ 균일, 경계 바깥 $\sigma_{\theta\theta} = +E\varepsilon/2 = \mathbf{+50\text{ MPa}}$ (NAFEMS 기준값과 같음), $\sigma_{rr} = -50\text{ MPa}$. (단, 본 시험은 무한판 해석해 기준이며 Coreform 원문의 `surrounding-material side` 프로브 오프셋 및 proprietary function splitting 수식은 비공개.)
