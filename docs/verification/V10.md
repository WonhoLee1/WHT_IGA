## Bossak 대 HHT 차이

두 방식은 같은 Newmark 계수 (γ = ½ − α, β = (1−α)²/4)를 쓰지만 α가 놓이는 곳이 다르다 (Bossak: 관성항, HHT: 힘·강성항). 작은 |α|에서는 주기 연장이 거의 같다 (TF: −0.930 % 대 −0.93 %). |α|가 클수록 분산·소산이 갈려 MD에서 0.4 %p 차이가 났다 (−1.59 % 대 −1.19 %). Abaqus MODERATE_DISSIPATION의 실제 α는 확인하지 못했고 계획서의 −0.30을 썼다. 두 f₁ 모두 2 % 기준 안이다. "Bossak이 HHT의 상위호환"이라는 표현은 쓰지 않는다 — 상위 일반화는 Generalized-α(Chung-Hulbert 1993)이며 HHT(`αm=0`)와 Bossak(`αf=0`)은 각기 다른 특수경우다. 위 1번 비교(Kratos↔Python)는 자체구현 일치이지 HHT 동등검증이 아니다. 감쇠율·진폭/에너지감쇠비는 Bossak 수치소산의 이론 처방값과의 일치도이며 재료·모드감쇠 같은 물리감쇠가 아니다.

## 한계

- Kratos Bossak 경로는 선형 문제, 집중 질량(행합)만 지원한다 (QP 일관 질량 0). 일관 질량 결과는 Python `solve_bossak_linear`로 얻는다. 비선형 경로(S21 규칙)는 구현하지 않았다.
- 집중 질량 f₁은 일관 질량보다 낮다 (TF 24697.5 Hz). 판정은 일관 질량 결과로 했다.
