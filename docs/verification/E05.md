## 1. 입력 요약 ([e05.json](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/tests/verification/data/e05.json) · [S43.md](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/docs/spikes/S43.md))

- **단위계**: MMTS (`mm`, `N`, `MPa`, `tonne/mm³`)
- **재료 모델** (모두 `E = 200,000 MPa`, `ν = 0.29`, `ρ = 8.0e-9 tonne/mm³`):
  - `weak_steel` (`hinge`, `link`, `pin_cap_l`, `pin_cap_r`): 2점 선형 외삽 등방성 소성 경화 `1,500 MPa @ ε_p = 0 → 150,000 MPa @ ε_p = 10` (`HARDENING_CURVE = 6`)
  - `strong_steel` (`pin_cyl`): 2점 선형 외삽 등방성 소성 경화 `2,000 MPa @ ε_p = 0 → 200,000 MPa @ ε_p = 10` (`HARDENING_CURVE = 6`)
- **경계조건 및 접촉 쌍**:
  - `link`: `pinned` (장착 플랜지 `U1 = U2 = U3 = 0`)
  - `hinge`: 강제 변위 `(U1, U2, U3) = (0, 0, 5) mm` (본 검증 다중 스텝 해석에서는 `u_z = 0.25 -> 0.50 -> 0.75 -> 1.00 mm`까지 가압해 항복·경화 구간 검증)
  - `pin`: Z 방향 Dirichlet 구속 없음(접촉으로만 평형, X/Y 강체모드용 미소 안정화 `k_xy = 1e-2 N/mm`, `k_z = 1e-6 N/mm`)
  - 3개 surface-to-surface 접촉 쌍 (`μ = 0.3`, finite sliding, 초기 간극/침투 보정 없음):
    - `pin_to_hinge_contact` (Main: `Pin`, Secondary: `Hinge`)
    - `pin_to_link_contact` (Main: `Pin`, Secondary: `Link`)
    - `hinge_to_link_contact` (Main: `Hinge`, Secondary: `Link`)
- **솔버 결함 수정 기록 ([contact_surface.py](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/analyses/contact_surface.py))**:
  - `NonlinearBodyOperator` 기본값 `ghost_alpha = 0.0` 사용 시 절단 격자의 비활성 제어점에 Kratos 방정식 ID가 할당되지 않아 `A.Size1() < box.n_dofs`가 되며 `eval()`에서 `IndexError`가 발생하던 결함을 확인·수정함(`mp.Elements`에서 실제 사용된 활성 DOF 집합 `_act_dof`와 Kratos 방정식 순열 `_eq_ids` 기반 `_P_act` 희소 주입 행렬 적용).
