## 가정과 한계 (판정에 영향)

1. **SRSS는 퇴화 쌍의 고유벡터 방향에 의존한다.** 정사각 단면의 굽힘 모드는 쌍으로 퇴화하고 `eigsh`가 임의 방향의 기저를 돌려준다. 같은 모델에서 충격 피크가 7.8–9.8e-4로 달라졌다 (Abaqus 모드는 축 정렬: |Γ_y| = 0.116 / 6.99). `align_degenerate_modes`로 가진 방향에 정렬해 결정적으로 만들었다. CQC·랜덤 응답은 회전 불변이라 영향이 없다 (단위 시험으로 확인).
2. **랜덤 RMS는 수렴 적분으로 판정했다.** 원문이 "20점·bias 3 sweep은 수렴 적분이 아니다(neither is the converged integral)"라고 밝히지만 Abaqus bias 공식을 적지 않았다. 가정한 두 공식의 20점 sweep은 +2.64 %(power) / +11.26 %(sinh)로 갈린다. 공식을 모르므로 Abaqus sweep과의 점별 일치(원문 2e-7)는 **검증하지 못했다**. 본 게이트의 Abaqus 참조값(RMS 340e-6, shock 965e-4)은 물리 정해가 아니라 body-fitted Abaqus 메쉬와 immersed 메쉬 간 차이의 허용치다(Coreform §6 Table 8, Accepted 50e-3) — PASS-단서 유지.
   - **원전 확정 (2026-11-15 초 딥리서치):** Abaqus Analysis User's Guide "Random Response Analysis > The Bias Parameter" (v6.11/2016/v2025 동일, MathML 직접 확인) — 지수 **`1/p`**, n은 구간당 양끝점 포함 개수, LOG는 로그공간 보간 후 exp. 현 구현(`_bias_map` abaqus 분기, 구간분할·unique 병합)과 일치. DB PSD 밴드표(1~15 풀옥타브)는 V09 평탄 BASE 입력과 무관 → 범위 제외 유지.
3. **TENP / GRP / DSC 정의.** 계획서는 TENP를 "그룹 합"으로 적었으나 Coreform 원문은 "10 % 이내 모드 쌍에 교차항을 더하는 방법"(TENP), "그룹 합 후 SRSS"(GRP)이다. 원문을 따랐고 세부(비전이적 순차 그룹 `w≤1.1·w_start`, 그룹 내 `|R|` 합, DSC Rosenblueth-Elorduy + duration 보정 `xi'=xi+2/(w·td)`)는 NRC RG 1.92 교과서 형태를 가정한 것이다 (NRC 인용은 Abaqus 6.3.10 경유로 한정). GRP 그룹 내 합은 Coreform 원문의 "부호합" 관측치와 다를 수 있음을 명시한다. V09 판정은 SRSS만 쓰므로 영향이 없다.
4. 규칙 손계산 일치(`1e-13`~`1e-14`)는 **구현이 명시한 식과 같음**의 검증이며 Abaqus 구현과의 일치가 아니다.
5. 미지원(명시적 오류): `DB` PSD(밴드 번호표가 원문에 없음), `FORCE` PSD, 회전 기저 운동, 복소 교차 PSD.
