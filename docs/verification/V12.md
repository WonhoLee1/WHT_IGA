## 구성

- 전도 행렬 `K_th`: **Kratos `LaplacianElement`**(QP 요소, 요소별 `CalculateLocalSystem`을 제어점 번호로 산포)로 만들고, 독립 Python 조립과 `1.4e-16`(p=1)/`2.5e-16`(p=2)로 일치함을 시험한다. 요소 단위 조립이라 Dirichlet 처리 없는 전체 행렬이 나온다 (블록 빌더는 고정 DOF 행·열을 0으로 만든다).
- 용량 `C_th = ∫ρc NᵀN dV`, 필름·복사 면 항, Newton, 시간적분은 Python이다. 이유: Kratos `LaplacianElement::CalculateMassMatrix`는 `k NᵀN`이라 ρc가 없고, QP 표면의 `SupportLaplacianCondition`/`ThermalFace`는 사용할 수 없다 (스파이크 S11).
- 시간적분: BE / CN / BDF2 (시험에서 차수 1·2·2 확인). 스텝은 연구의 적응 0.1–0.5 s 대신 고정 0.025–0.05 s.
