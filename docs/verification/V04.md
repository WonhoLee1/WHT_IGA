## 1. 입력 요약

- 단위계: MMTS (`mm, tonne, s, N, MPa`) — [v04.json](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/tests/verification/data/v04.json) 준거

- 재료 물성:
  - 구리(Cu, $y < 0$): $E = 1.0 \times 10^5\text{ MPa}$, $\nu = 0$
  - 텅스텐(W, $y > 0$): $E = 4.0 \times 10^5\text{ MPa}$, $\nu = 0$
- 경계조건 및 하중: $z = 0$ 고정단 전 변위 구속, $z = 100\text{ mm}$ 자유단 전단 트랙션 $t_y = -0.01\text{ N/mm}^2$ (합력 $P = 1.0\text{ N}$)
- 비교 모델 3종 (`degree=2`):
  1. **순수 IGA $C^0$ 병합**: 단일 `BoxSpline (2, 4, 16)` 계면 $y = 0$ 이중 매듭(`[-5, -5, -5, -2.5, 0, 0, 2.5, 5, 5, 5]`), 셀 중심 좌표 $y_c$ 에 따라 Cu/W 물성 분리 할당
  2. **순수 IGA 2-파트 Tie**: Cu/W 개별 `BoxSpline (2, 2, 16)` 파트를 [`AssemblyBuilder`](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/kratos_backend/assembly_builder.py)로 조립하고 계면 $y = 0$ 에 `TieSpec(..., method="mpc_matching")` 적용
  3. **IGA–FE 하이브리드**: Cu 파트는 Native FE `hex8` (`2 x 4 x 300`, [`native_fe.py`](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/kratos_backend/native_fe.py)), W 파트는 IGA `BoxSpline (2, 2, 16)` 으로 조립하고 [`SurfaceMesh.from_fe`](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/kratos_backend/interactions.py) ↔ [`SurfaceMesh.from_iga_face`](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/kratos_backend/interactions.py) 계면에 `TieSpec(..., method="auto", penalty_beta=1.0e3, E_max=4.0e5)` 결합 후 [`solve_hybrid_iga_fe`](file:///D:/PythonCodeStudy/CAD-CAE-COPILOT/WHT_IGA/wht_iga/kratos_backend/native_fe.py) 해석
