## 3. 열린 과제 (우선순위)
1. **E03 Newton 수렴(솔버)**: 실패 위치는 `heat_to_200` 시작부(레벨 2.00–2.01). `max_iters` 30→60은 효과 없음. 다음 단계는 잔차 계측이다. Kratos Newton echo가 표준 출력에 나오지 않았다. 후보: 재료 법칙(−55 °C 열-소성 테이블 외삽), 라인서치, 접선 예측자, 상태 커밋 순서. 재현 스크립트: `scripts/review_20261123/e03_csv_levels_hist.py`.
2. **E04 C⁰ 정식화**: 문서 식 `U(p,C^(p−2),h)/P(0,C^(−1),h)`는 변위와 압력에 같은 `h`를 쓴다. 따라서 셀당 P0 구현(현재 C⁰ 경로)이 문서와 같을 가능성이 크다. 기준값 6.98946이 어느 격자에서 나왔는지는 명세에 없다(`mesh_sweep.status=unknown`). 필요한 것: Cook 저널(공개 다운로드, 아래 4절).
3. **V06 p=1 L0**: 문서의 "p 패딩 요소"와 "h=0.1/2^k" 규칙은 이미 반영 가능. 패딩 12³ 격자는 이전 시험에서 ≥1.02e-2로 맞지 않았다. Coreform 메쉬는 6,585 DOF(≈13³ 노드×3)와 2,860 U-spline 부분 요소로 기록되어 있어, 부분 요소 구성 방식이 핵심 미지수다. 메쉬 inp 파일이 있으면 바로 검증 가능.
4. **V12 T3**: 1차원 재현(`scripts/review_20261123/t3_1d.py`)에서 consistent 용량과 후진 오일러 dt별 값을 확인했다. 판정 방식(방법 재현으로 충족 처리할지)은 사용자 결정 사항.
5. **V10 HHT**: Python HHT 구현 여부 결정 필요(Kratos에는 없음). 구현 시 α=1−√2 근방에서 MODERATE 재현 가능성이 있으나 추론이며 검증 전이다.
6. **V09**: Coreform 랜덤 응답 RMS 정의(PSD 적분 방식, 상대/절대 변위)가 필요하다.

- 게이트와 허용치는 측정값에 맞춰 바꾸지 않는다. 충족 전환은 실제 개선 또는 근거 있는 해소로만.

- 결과 파일(≥100 MB)과 `.omc`, `.cache`는 저장소에 넣지 않는다.
- 메모리 사용: 대형 해석은 한 번에 하나. 이 PC는 32 GB, 가용 약 17 GB를 기준으로 판단.
