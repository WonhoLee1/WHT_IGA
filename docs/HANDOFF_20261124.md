## 2. E03 — 원인 확정과 해소
- 증상: Coreform 수락 증분 45개(단계당 15)를 재현하면 컷백 3(`heat_to_200` 첫 증분, 레벨 2.00–2.01).
- 분리 실험: 금속 탄성 → 컷백 0. 304L −55 °C 행을 20 °C 행으로 바꾸면 가열 시작부 실패가 사라짐(대신 냉각 중 1회). −55 °C 행은 Coreform 입력 자료이므로 바꾸지 않는다.
- Newton 이력: 실패 증분은 상대 잔차 4e-7까지 선형 수렴 후 4e-7–1e-6에서 정체(발산 아님).
- 원인: Kratos J2 반환 사상의 국소 허용치 `F ≤ 1e-4·threshold`(`generic_cl_integrator_plasticity.h:199`, 하드코딩)가 전역 잔차 바닥을 만든다. Kratos 잔차 기준은 증분 초기 잔차 대비 비율이라, 크기 0.01의 작은 증분에서 바닥이 1e-8보다 크다.
- 근거: Coreform E03는 Abaqus/Standard 풀이, 수렴 제어 변경 없음(기본 잔차 허용치 5e-3), CSV 평형 반복 1–2회/증분.
- 조치: Coreform 이력 재현 시험에서 `tol_rel = 1e-6`. 결과 45/45, 컷백 0, Newton 3–7회. 단계 끝 응력·PEEQ는 1e-8 실행과 최대 3.1e-8 상대 차이.
- 코드: `TP.run_thermal_steps(levels=...)`와 `TP.check_levels` 추가(명시 일정 재현). 시험 `test_e03_p2_coreform_increment_history_replay`(slow, 198 s 통과), `tests/unit/test_thermal_level_schedule.py`(10 통과). 기존 균일 일정 게이트 시험(1e-8)은 바꾸지 않았다.

## 3. V06 L0 p=1 — 원인 확정
- 독립 계산(Kratos 없음, 같은 절단 셀 적분표, 강한 대칭, 확장 없음, 정확한 구면 압력): Galerkin u 1.007 %, 에너지 투영 1.007 %, L2 최적 근사 0.085 %. Kratos 1.01–1.02 %와 같다. 하중·경계·솔버 결함 없음.
- Coreform 문서: 배경 격자는 (N+2p)³(p=1: 12³), 활성 셀 343(우리와 같음). p=1에서는 패딩이 영역 안 공간을 바꾸지 않는다. 그러나 Coreform Abaqus 모델은 요소 2,860 / 절점 2,195(우리 셀 343 / 활성 제어점 644). 이산 공간 구성이 다르며 비공개.
- 앞 인계의 "6,585 DOF ≈ 13³ 노드×3" 해석은 틀렸다(2,195는 Abaqus 절점 수, 13³=2,197과 우연히 가까움).
- **정정(같은 날 후속):** Abaqus 요소·절점 수에는 하중·경계용 SFM3D3 표면 요소가 포함되므로 "이산 공간이 다르다"는 해석도 근거가 없다. 문서 기반 재구성으로 확인한 기제는 절단 셀 적분이다: q=2(정확) 대 q=1(과소)에서 Coreform의 네 오차(u, u_r, σrr, σθθ)가 모두 두 점 사이 같은 비율에 놓인다(h0p1 약 0.5, regproj·wt2 변형 약 0.7). 벌점 대칭과 테셀레이션은 기각. Coreform 적분 규칙은 비공개이고, q=1은 L1 σrr 허용치를 넘어 일관된 재구성이 아니므로 채택하지 않았다.
- L0 p=2 현 코드: Kratos u 5.82e-5 = 독립 Galerkin 5.86e-5. `docs/phase2/evidence/v06_drop/L0_p2_drop.json`의 9.17e-4는 이전 코드 결과다(현 증거는 `v06_nnlsfix/`).
- 필요한 것: Coreform 메쉬 입력(`<iga-mesh-inp>`).

## 4. E04 — p=3 시험과 ν = 0.495 전환
- Coreform 식 U(p, C^(p−2))를 p=3(C¹)에 적용: n=8 +20.74 %, n=16 +11.98 %. e04.json상 Coreform 모델은 이차(p=2) 몸체 맞춤이므로 p=3은 Coreform 구성이 아니다. n=32(수 시간)는 돌리지 않았다.
- 사용자 결정(2026-11-24): ν = 0.49999는 과하므로 ν = 0.495로 전환. 계산 전 기준: C⁰·C¹ 극한 일치 ≤ 1 %, 최세 C⁰ ≤ 1 %. 결과: C¹ 7.0694/7.0144/6.9880, C⁰ 7.6482/7.3080/7.1327(16/32/64), 극한 6.964/6.947 → 첫 기준 충족, 둘째 불충족(+2.4 %). 느린 수렴은 모서리 특이점 때문(ν 영향 작음). Kratos 기본 TL p=1 5.082(잠김), Q1P0 NaN. 128×128은 사용자 결정으로 보류.

## 5. V10 — HHT 적용
- Kratos 조사: 구조 동해석 솔버는 newmark·bossak·bdf·pseudo_static·relaxation. Kratos core `TimeDiscretization::GeneralizedAlpha(αm, αf)`가 HHT(αm=0, αf=−α)를 포함(파이썬 바인딩 없음, 계수 식을 옮김).
- `GeneralizedAlphaConfig`, `solve_generalized_alpha_linear` 추가(αf=0이면 Bossak과 같음). Abaqus 프리셋 TF α=−0.05, MD α=−0.41421.
- 결과: TF 24770.26 Hz, MD 24705.50 Hz. Coreform 몸체맞춤 대비 +0.007 %, 침지 대비 +0.014 %. 모달 주파수·감쇠는 HHT 이론과 일치. 시험 `test_v10_vibrating_beam_hht[*]` 통과.
