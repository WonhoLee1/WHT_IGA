# S20 Accessor 및 온도 의존 물성 $E(T)$, $\alpha(T)$

- 질문: Kratos `Accessor`(위치·온도 기반 물성 접근자 또는 `Properties` + `TableAccessor` / Python Accessor)로 적분점별 온도 의존 $E(T)$, $\alpha(T)$를 강성/열변형에 반영할 수 있는가?
- 결과: **부분적 예 (`ThermalElasticIsotropic3D` + `TableAccessor`로 $E(T)$ 반영 가능, 오차 `< 1e-8`; `LinearElastic3DLaw`와 $\alpha(T)$는 Accessor 미지원 → 셀/요소별 `Properties` 복제로 해결)**
- 근거:
  - `pytest WHT_IGA/tests/kratos_spikes/test_s20_accessor_temp.py` 6/6 통과
  - Python 바인딩 구조: `TableAccessor`는 Python `KratosMultiphysics`에 직접 노출되어 있지 않으나(`not hasattr(KM, "TableAccessor")`), `ReadMaterialsUtility`의 JSON `"accessors"` (`"accessor_type": "table_accessor"`)를 통해 C++ `TableAccessor`를 생성하여 `props.HasAccessor(KM.YOUNG_MODULUS) == True`로 부착 가능
  - `SM.LinearElastic3DLaw`: `elastic_isotropic_3d.cpp:368,383`이 `r_props[YOUNG_MODULUS]`를 직접 조회하여 `TableAccessor`를 무시함(선형 온도 구배 $T(x)=100x$ + `E(T)=100+T` 테이블 설정 시에도 상수 $E_0=100$ 응력 `1.0` 반환, 상수해와 차이 `4.108e-15`)
  - `CL.ThermalElasticIsotropic3D` — 자유 열팽창($T(x)=100x$, $\alpha=10^{-5}$, $\nu=0$, 4셀 p=2): 끝단 변위 `5.000000000000e-04` (해석해 $0.5\alpha\Delta T L$과 오차 `6.505e-19`), 잔류 응력 `2.277e-16`
  - `CL.ThermalElasticIsotropic3D` + `TableAccessor` $E(T)$ — 양단 구속 열응력 막대($E(T)=100+T$, $T(x)=100x$, $\alpha=10^{-5}$, $\nu=0$): `p=4, n_x=24`에서 평균 응력 `-0.072134752478` vs 해석해 `-0.072134752044` ($\sigma_0 = -\alpha E_1 \Delta T^2 / (2 \ln(1+E_1\Delta T/E_0))$), **상대오차 `6.013e-09` (목표 `1e-8` 달성)**
  - `CL.ThermalElasticIsotropic3D` + `TableAccessor` $\alpha(T)$: `SubstractThermalStrain` (`advanced_constitutive_law_utilities.cpp:786`)이 `rMaterialProperties[THERMAL_EXPANSION_COEFFICIENT]`를 직접 읽어 `TableAccessor`를 무시함(상수 $\alpha_0$ 해와 차이 `1.084e-19`)
  - 대안 경로 검증 — 셀/요소별 `Properties` 복제(`mp.GetProperties()[eid]`에 셀 중심 온도 $T_c$의 $E(T_c), \alpha(T_c)$ 부여): $E(T)$와 $\alpha(T)$ 동시 의존 양단 구속 막대(해석해 `-0.168314421437`)에서 `n_x=8, 16, 32` (p=2) 상대오차 각각 `2.605e-04`, `4.953e-05`, `1.049e-05`로 $O(h^2)$ 수렴 실측
- 환경: Python 3.12.16, Kratos 10.4.3 (`E:\kratos-build\install`), 2026-11-14
- 결론과 영향:
  1. $E(T)$만 필요한 열-탄성 해석은 `ReadMaterialsUtility` JSON + `TableAccessor` + `ThermalElasticIsotropic3D`로 적분점 수준 정밀도(`< 1e-8`)를 달성할 수 있음.
  2. $\alpha(T)$까지 온도에 의존하거나 `LinearElastic3DLaw`를 쓰는 경우에는 셀별 `Properties` 복제(또는 `Properties` ID를 셀당 1개씩 생성)를 사용해야 함.
