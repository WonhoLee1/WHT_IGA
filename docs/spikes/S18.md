# S18 Nitsche support (3D)

- 질문: `SupportNitscheCondition` 3D 지원? (v2 §5.8 S18, 정보성)
- 결과: 아니오 (3D 솔리드 불가; 2D 멤브레인 전용)
- 근거 (`tests/kratos_spikes/test_s18_nitsche_support.py`, 1 passed + 스크래치 segfault 재현):
  1. 표면 QP 기하에 조건 생성은 성공 (생성 자체는 안전).
  2. 3D 솔리드 속성집합은 subproperty 0개 (in-test 확정). 조건은 `GetProperties().GetSubProperties().front()`를 무조건 역참조 (`support_nitsche_condition.cpp` l.182, 343, 355, 597, 608) → 빈 컨테이너 접근으로 segfault (스크래치 `dbg_nit.py`에서 `CalculateLocalSystem` 호출 즉시 access violation, in-test 미실행).
  3. 조건 내부는 멤브레인 운동학 (PK2 응력, THICKNESS, PRESTRESS) — in-tree Nitsche 테스트도 `LinearElasticPlaneStress2DLaw` + THICKNESS/PRESTRESS 멤브레인 설정. 3D 솔리드용 Nitsche 조건은 이 빌드에 없음. `Check()` 오버라이드도 없어 안전한 실패 경로가 없음.
- 환경: Python 3.12.16 (whtiga), Kratos 10.4.3 소스빌드 (`E:\kratos-build\install`), 날짜 2026-11-14
- 결론과 영향: v2 failover 적용 — 3D Nitsche는 C++ 트랙으로 (Phase 6 선택). Phase 1은 penalty 기본 (S09 성립). 경로 결정 영향 없음 (정보성 spike).
- 재현: `... python -m pytest WHT_IGA/tests/kratos_spikes/test_s18_nitsche_support.py`
