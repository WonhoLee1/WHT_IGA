## 전체 E05(`RF3 = -46.946 kN`) 달성을 위한 잔여 갭
1. **소성 경화(Plastic hardening) 통합:** 현재 선행 모델은 선형 탄성(`SmallDisplacementElement3D4N`)을 사용한다. 전체 E05는 `weak_steel`/`strong_steel`의 2점 선형 외삽 등방성 소성 경화(J2, `1500 -> 150000 MPa`, `2000 -> 200000 MPa` @ `eps_p=10`)를 접촉 루프와 결합해야 한다.
2. **대변형·유한 미끄럼(`5 mm` finite sliding):** 전체 변위 `(0, 0, 5) mm` 하에서 원통 핀과 clevis 구멍 사이의 대변형 기구학(`TotalLagrangianElement3D4N` / `contact_nlgeom.py`) 및 다중 증분 하중 스텝(`initial_inc = 0.1`)이 필요하다.
3. **실제 3D Trimmed CAD 표면 접촉 투영:** 현재 `DeformableBoxFaceMaster`는 BoxSpline 경계면에 투영한다. 실제 E05 원통 핀–구멍 간 접촉을 위해서는 trimmed B-Rep 경계 삼각형(`SFM3D3` / `Triangle3D3`) 기반의 3D 곡면 투영기 및 다중 접촉 쌍(`3-part`) 지원이 필요하다.
4. **정확한 원전 CAD 치수 확보:** 원전 문서에 STEP/ACIS 파일이 포함되지 않았으므로, `-46.946 kN`의 정량적 대조(`±5%`)를 위해서는 실제 Coreform 예제 CAD 지오메트리가 필요하다.
