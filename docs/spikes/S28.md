# S28 열-소성: Kratos J2에 열변형률을 초기 변형률로 주기 (IGA 적분점 요소)

## 질문
Kratos 10.4에는 열-소성 구성법칙이 없습니다. 그래도 E03(온도 의존 J2 + NLGEOM 열 step)을 Kratos 경로로 풀 수 있을까요?

## 결과: 예. 초기 변형률 우회가 해석해와 정확히 일치합니다(기계 정밀도).

### Kratos 소스에서 확인한 사실 (`D:\PythonCodeStudy\kratos-src`, 읽기 전용)
- 열 관련 법칙은 다음뿐이고, 열-소성은 없습니다.
  - `ThermalElasticIsotropic3D` 등 열탄성
  - `SmallStrainThermalIsotropicDamage*` 열 손상
- 일반 소성 법칙은 초기 변형률 ε₀(`InitialState`)를 응력 계산과 상태 확정 양쪽에서 똑같이 뺍니다(ε − ε₀).
  - 해당 법칙: `SmallStrainIsotropicPlasticity3DVonMisesVonMises`, `FiniteStrainIsotropicPlasticity3DVonMisesVonMises`
  - 근거: `generic_small_strain_isotropic_plasticity.cpp`의 `CalculateMaterialResponseCauchy`와 `FinalizeMaterialResponseCauchy`
  - 따라서 ε₀ = αΔT·[1, 1, 1, 0, 0, 0]이 열변형률 역할을 합니다.
- 설정 방법은 `KM.SetInitialStateProcess3D(model_part, ε₀, σ₀ = 0, F₀ = I).ExecuteInitializeSolutionStep()`입니다.
  - 요소별 값은 형상 데이터(`Geometry.SetValue`)로 줄 수 있지만, Python에 바인딩되어 있지 않습니다.
  - 그래서 **셀 그룹마다 부분 모델 파트**를 만들어 같은 처리를 반복 실행합니다.

## E03 적용 시 주의
- **열변형률은 요소(= 셀) 단위로 일정합니다.**
  - 적분점마다 다른 온도는 줄 수 없습니다(처리 과정이 요소의 모든 적분점에 같은 상태를 씀).
  - 온도장은 셀 평균으로 처리하거나 셀을 세분해야 합니다.
- **온도에 따른 E·항복응력**
  - 셀별 Properties를 복제해 단계마다 값을 갱신합니다(S20 방식, 항복응력 갱신은 위에서 확인).
  - E(T)는 `TableAccessor`도 가능합니다(S20).
- **대변형:** Green–Lagrange 변형률에 열변형률을 더하는 방식입니다(가산 분해). 열변형률이 10⁻³ 수준이라 적합합니다.
- **비용:** 셀이 많으면(E03은 배경 요소 146k) 부분 모델 파트와 처리 과정의 반복 비용이 문제입니다. 온도 구간별로 묶어야 합니다.
