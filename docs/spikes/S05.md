# S05 구속식 성능·정확도

- 질문: `LinearMasterSlaveConstraint`(3 slave × 81 master) 1e5개를 30초 안에 생성, Block B&S로 풀이, slave 값 복원? 요소가 없는 master 전용 노드의 자유도가 DofSet에 들어가나?
- 결과: 예
- 근거:
  - `pytest WHT_IGA/tests/kratos_spikes/test_s05_constraints.py` 3/3 통과
  - 정확도: 3×2×2셀 p=1(108 DOF), slave 20개×각 master 27개 난수 T, x=0면 고정 + x=L면 지정변위. Kratos 해 vs scipy 직접 푼 TᵀKT 해: 최대 오차 4.163336342344337e-17 (허용 1e-10). slave 복원 오차 2.4936649967166602e-18 (허용 1e-12)
  - 성능: 1e5개 구속 생성 2.7초 (목표 30초 이내). 조립+풀이(pardiso) 32.0초. slave 상수 복원(100점 샘플) 오차 < 1e-9
  - DofSet: 요소 없는 lone master 노드 3개 자유도 eq id [24, 25, 26]으로 포함됨 (24개 요소 DOF + 3개)
- 환경: Python 3.12.16, Kratos 10.4.3 (`E:\kratos-build\install`), 2026-11-14
- 결론과 영향:
  - R1 구속식 경로 성립. R2(추출 경로) 불필요. K12 우려(DofSet 누락) 없음 — 단 노드는 AddDof 호출 전에 생성되어야 함(K14, `make_nurbs_volume`가 전체 AddDof하므로 그 이전 생성 권장)
  - 중요 규칙 발견: Dirichlet 고정된 master를 관계식에서 제외하고 상수에 미리 접어넣으면 상수가 이중 계산됨(slave = Ru + 2c 관측). 고정 master는 관계식에 그대로 두고 c=0으로 해야 함. `constraints.py` docstring에 기록, S05-A가 이 규칙으로 4.2e-17 달성
  - 바인딩 순서: `CreateNewMasterSlaveConstraint`는 master 리스트가 먼저 (C++ `CreateNewMasterSlaveConstraint1` 확인)
  - 1e5 조립+풀이 32초는 측정값 그대로 보고. Phase 6 성능 게이트와 별개로 주시
