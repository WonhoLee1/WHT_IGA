- 결과: 부분 (Kratos 풀이 경로는 실패, T-투영 수학은 검증됨)
- 근거:
  - `pytest WHT_IGA/tests/kratos_spikes/test_s06_eigen.py` 4/4 통과
  - 정상 경로(대조군): 표준 hex 외팔보 analysis-stage 고유치 [0.002781692366177655, 0.0027816923661779028, 0.049985403281236095]. EB 해석값 ω1²=0.0016483151203058406 대비 1.69배(거친 선형 격자, 3배 이내 허용). 1·2차 일치(두 휨면)
  - 근본 원인: QP 기하 요소 `CalculateMassMatrix` 합 = 0.0 (대조군 hex = 6.0 = 3×ρV). `CalculateLumpedMassVector`는 정상(6.0). EigensolverDynamicScheme이 consistent M을 쓰므로 QP 격자에서 generalized EVP가 성립 불가
  - QP 외팔보 analysis-stage 고유치: [0.0, 0.0, 0.0] + "Eigen solution was not successful!" 경고 (프로브에 따라 1e170 garbage — 비결정적, 일관되게 실패)
  - 수학 검증(scipy): Kratos 추출 K 아님 — S04에서 동일 이산화 K가 참조 조립기와 1e-16 일치 proven이므로 참조 K + 자체 consistent M(Gauss, 합=3ρV·대칭 검증) + eigsh → [0.0027816923661811935, ...] hex-Kratos값과 ~1e-9 일치, EB와 3배 이내. T-투영(팁 중복노드 tie) 구속 스펙트럼 vs 무구속: rtol 1e-8 일치, 가짜 모드 없음

  - R1 정적 해석에는 영향 없음. 동역학/고유치(Phase 4)가 QP 기하에서 Kratos solver로 불가 → failover "추출 행렬 + scipy eigsh" 적용. 단 M 추출도 불가하므로 M은 자체 조립(lumped는 Kratos 추출 가능: 합 6.0 확인)
