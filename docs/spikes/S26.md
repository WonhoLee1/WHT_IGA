# S26 Python 반평활 Newton 접촉 + Coulomb 마찰 + 바이메탈 열응력 (Track 3 Phase 5 선행)

- 질문: 고수준 Kratos 접촉 프로세스 없이 Python 레벨에서 무마찰 Hertz 접촉력,
  Coulomb 마찰 plateau, 2-재료 열응력을 검증할 수 있는가?
- 결과: 예 (3/3 신규 테스트 통과 대상).
- 근거:
  - `pytest WHT_IGA/tests/kratos_spikes/test_p5_nlgeom_contact_prep.py` 신규 3건:
    `test_p5_bimaterial_thermal_clamped` (E03 축소판, 해석해 대비 1e-9),
    `test_p5_hertz_ssn_coarse` (NX=12 SSN, 잔차 1e-6, F_N 35%),
    `test_p5_friction_plateau_mu` (return map, F_T/F_N → μ).
  - Hertz 세분화 추세 (probe_hertz4, 1/4 대칭, k=1e4):
    NX=12 err 26% → NX=24 err 16.8% → NX=48 err 7.1% (48/2401 active, 5회, 855s).
    잔차 = 유한 깊이(h=2, 반무한체 아님) + penalty compliance + 성김이산화.
  - 마찰 슬라이딩 probe (probe_friction, 40스텝): step 1-29 stick ramp,
    step 30부터 F_T/F_N = 0.3000 고정 (μ=0.3). ux_slip = μ·k_n·depth/k_t = 0.06 일치.
  - E03 축소판 probe (probe_e03): 2-재료 고정단 균일 dT, 해석해와 5.7e-16 일치 (S20 경로).
- 발견 사항:
  1. Staggered penalty 고정점은 k·C >> 1이면 ω와 무관하게 발산 (ω_crit ≈ 0.05).
     반평활 Newton (Kratos 추출 K + nodal penalty + 일치 tangent)이 정답.
     3-5회 반복, 잔차 1e-12 ~ 1e-13.
  2. SpringDamperElement 분해 시도는 부호 오류로 기각 (초기 침투를 모름).
  3. `SmallStrainJ2Plasticity3DLaw`는 열변형률 미지원 (Kratos 10.4에 thermal J2 법칙 없음).
     E03 축소판은 탄성 바이메탈로만 검증; J2+열 결합은 불가로 문서화.
  4. `Solve()` 반환값이 아닌 `IsConverged()`로 판정 (S19 보완).
     BC 적용 후 `CloneTimeStep` 금지 (UL 0 붕괴, S19 보완).
