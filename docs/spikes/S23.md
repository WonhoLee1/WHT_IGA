# S23 비정합 계면 MPC 가중치 (`nearest_element` mapper & `AssignMasterSlaveConstraintsToNeighboursUtility`)

- 질문: `AssignMasterSlaveConstraintsToNeighboursUtility` 또는 `MappingApplication`의 `nearest_element` mapper로 비정합 계면 MPC 가중치를 만들 수 있는가?
- 결과: **부분** (`MappingApplication` `nearest_element` mapper는 단위 분할·선형 좌표 재현 `1.110e-16`, 일정 변위 패치 `5.551e-17`, 운동학적 선형 변위 전달 `4.441e-16`으로 목표 `1e-12` 통과; 단, 양측 계면 자유도가 모두 자유롭고 비영 응력이 있는 결합 선형 패치에서는 비변분적 collocation 오차 `0.085987` 발생. `AssignMasterSlaveConstraintsToNeighboursUtility`는 선형 재현 오차 `7.942e-2`로 `1e-12` 미달)
- 근거 (`tests/kratos_spikes/test_s23_nonmatching_mapper.py`, 5/5 통과):
  1. `nearest_element` 가중치 행렬 $W$ (`2x2` 삼각망 9노드 → `3x3` 삼각망 16노드):
     - Partition of unity 오차: `pou_err = 0.000e+00` (`< 1e-12`)
     - 선형 좌표 재현 오차 ($\|W X_m - X_s\|_\infty$): `coord_err = 1.110e-16` (`< 1e-12`)
  2. 비정합 두 블록(`2x2x1` vs `3x3x1`, p=1) 일정 변위 패치 `u=(0.1, -0.2, 0.3)`: `max_u_err = 5.551e-17` (`< 1e-12`).
  3. 운동학적 선형 변위 패치 (`u=(x, 2y, 3z)`, 계면 master에 정확 변위 부과 후 $W$로 slave 블록 구동): `max_u_err = 4.441e-16` (`< 1e-12`).
  4. 자유 계면 결합 선형 변위 패치 (`u=(x, 2y, 3z)`, $\sigma_{zz}=3 \neq 0$, 양측 계면 자유): `max_u_err = 0.085987` (Node 14에서 `u_z = 2.914013` vs `3.0`). 원인: 단순 nodal collocation MPC ($u_s = W u_m$)는 $\int_\Gamma N_m dA = W^T \int_\Gamma N_s dA$의 변분적 트랙션 일관성을 만족하지 못함.
  5. `AssignMasterSlaveConstraintsToNeighboursUtility` (radius=0.75, 동일 `2x2`→`3x3` 계면): 구속식 48개 생성, 운동학적 선형 변위 재현 오차 `7.942e-02` (RBF 기반 보간으로 `1e-12` 선형 패치 미달).
- 환경: Python 3.12.16 (`whtiga`), Kratos 10.4.3 소스빌드 (`E:\kratos-build\install`), 2026-11-14
- 결론과 영향: 비정합 계면의 운동학적 MPC 가중치 생성에는 `AssignMasterSlaveConstraintsToNeighboursUtility`(오차 `7.94e-2`) 대신 `MappingApplication`의 `nearest_element` + `GetMappingMatrix()`(오차 `1.11e-16`)를 사용해야 한다. 다만 응력이 작용하는 자유 계면에서 `1e-12` 수준의 변분적 패치 시험을 통과하려면 단순 collocation MPC가 아닌 mortar($L^2$ projection) 또는 Nitsche 결합이 필요하다.
