# S11 thermal conduction / film / radiation

- 질문: IgaApp `LaplacianElement` + `SupportLaplacianCondition` 3D, BDF 과도, slave 표면층 위 `ThermalFace3D3N` film/radiation 동작하나? (v2 §5.8 S11)
- 결과: 부분 (항목별: 전도 예 / Laplacian조건 아니오 / BDF 과도 아니오 / film 예 / radiation 예)
- 근거 (`tests/kratos_spikes/test_s11_thermal_laplacian.py`, 5 passed; bar 1×0.1×0.1, 2셀 p=1, k=1):
  1. 정상전도 (양면 강제가정, T=0/100): T(x=0.5) = 50.0000000000 정확. `LaplacianElement` 3D + QP 기하 성립.
  2. `SupportLaplacianCondition`은 사용 불가: 적분점당 QP 기하에 `Normal(0, method)` 미정의로 RuntimeError (`[QUADRATURE_POINT_SURFACE_IN_VOLUME_GEOMETRY] Normal not defined`, in-test `pytest.raises`로 확정); 노드 없는 wrapper 기하에 붙이면 segfault (스크래치 재현, in-test 미실행). → 열 Dirichlet는 강한 부과(노드 Fix) 사용. v2 §5.4의 "SupportLaplacianCondition penalty" 가정 수정 필요.
  3. BDF 과도 불가: `LaplacianElement::CalculateMassMatrix`가 전도도만 곱함 (`laplacian_element.cpp` l.158-166, rho·c_p 없음). in-test 기하-기반 일관질량과 1e-12 일치 확인 (M[0,0]=1.851852e-04). 즉 과도 열용량 행렬이 물리적으로 틀림 → 과도는 참조 조립기(Phase 1 `assemble_thermal`)가 맡아야 함.
  4. film (BC-C: 독립 carrier 삼각망 + 스플라인 보간 MPC + `ThermalFace3D3N`, h=2/T∞=100): n=1 평균 T(1)=66.542 (오차 0.124), n=2 → 66.659 (오차 0.008, 해석해 66.667). 에너지 보존 |Q_cond|=|Q_film| 1e-6 일치 (6.65e-01). 삼각 분할 film은 대각 꼭짓점에 하중 2배(valence 2 vs 1)라 O(h) 비균일 오차 — 세분화 수렴으로 입증, bug 아님.
  5. radiation (eps=0.5/T∞=100): T(1) = 2.8350 vs 스칼라 Ньютон근 2.8350 (1% 내). Newton loop 수렴.
  - 부수 발견 3건 (반드시 설정): settings에 TEMPERATURE_GRADIENT 미설정 시 solve 중 segfault; FACE_HEAT_FLUX(surface source) 미설정 시 ThermalFace에서 segfault; `ThermalFace3D3N`·Laplacian조건은 QP 기하에서 segfault하므로 carrier 일반 삼각형에만 사용.
