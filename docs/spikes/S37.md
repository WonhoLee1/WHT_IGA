## 질문
검증 결과를 제3자가 열어볼 수 있는 표준 포맷으로 모두 뽑아낼 수 있는가?

## 결과: 예. `wht_iga/post/evidence.py` + `test_evidence.py` 3/3 통과.
- 단일 Kratos solve → vtkhdf(자사) + vtu/msh/fem(meshio) + stl(외피 삼각화) + png(변형 컨투어).
- `.fem` = Nastran bulk data (meshio) → OptiStruct 직접 판독 가능.
- `.msh` = Gmsh, `.vtu` = ParaView, `.vtkhdf` = 자사 리더로 roundtrip 검증.
- `hvascii` (HyperView ASCII)는 in-repo·meshio 모두 writer 없음 → 명시적 범위 외
  (포맷 날조 금지 원칙).

## 발견·수정 2건 (정직 기록)
1. 3D 컨투어가 전부 어둡게 렌더링 → `Poly3DCollection.set_array` 경로 버리고
   면당 명시 RGBA (`facecolors=cmap(norm(...))`, `shade=False`)로 확정, 육안 검증.
2. 상대경로 + CWD 착각으로 패키지 내부(`wht_iga/docs/...`, 대소문자 함정)에 산출물
   기록 → 정위치 이동 + 잔재 삭제. 호출부는 절대경로 사용.
