## 1. 정식화

3장 Hu–Washizu $(u, \theta, p)$, $\theta$와 $p$는 같은 셀 단위 불연속 공간 $Q_c = \mathrm{span}\{\phi_k\}$:

$$\Pi(u,\theta,p) = \int W_{dev}(F) + \int U(\theta) + \int p\,(J-\theta),\quad W_{dev} = \tfrac{\mu}{2}(\mathrm{tr}\,C - 3),\quad U(J) = \tfrac{\lambda}{2}(\ln J)^2 - \mu \ln J$$

($W_{dev}$, $U$의 분할은 `fbar.py`와 동일). $p$, $\theta$에 대한 정류 조건은 셀 국소이고 닫힌 꼴로 소거된다(정적 응축, 전역 압력 DOF 없음):

$$\theta = \Pi_Q J,\qquad \hat p = \Pi_Q\,U'(\theta),\qquad E(u) = \sum_q w_q\,\tfrac{\mu}{2}(\mathrm{tr}\,C_q - 3) + \sum_q w_q\,U(\theta_q)$$

$\Pi_Q$는 셀 적분점 기준 $L^2$ 사영(기준 체적 가중치 $w_q$). $Q$ = 상수이면 $\theta = \bar J$로 `fbar`(Simo–Taylor–Pister)와 **정확히** 같다.

- **잔차 / 일관 접선** ($H_{qI} = F_q^{-T} G_{qI}$):
  $R_I = \sum_q w_q[\mu F_q G_{qI} + \hat p_q J_q H_{qI}]$,
  $K = K_{dev} + A^T C A + \sum_q w_q \hat p_q\,\partial(J_q H_{qI})/\partial u_J$,
  $A_{k,Ia} = \sum_q w_q \Psi_{qk} J_q H_{qIa}$, $C_{kl} = \sum_q w_q \Psi_{qk}\Psi_{ql} U''(\theta_q)$. 대칭(초탄성).
- **기저**: 셀별 단항식(전차수 $\le k$, 셀 중심·축별 스케일) → 셀 Gram 행렬 Cholesky 정규직교화($\Psi^T W \Psi = I$). P0 1개, P1 4개(1, x, y, z), P2 10개 모드.
- **좌표 선택(근거)**: 기본은 **물리(기준) 좌표 X** ("unmapped"). 곡선/비아핀 셀에서도 $P_k(X)$ 전체를 포함하므로 사영 오차가 $O(h^{k+1})$ 이다. 매개변수 좌표(mapped)는 점근적으로 아핀인 격자에서만 최적이다(Arnold–Boffi–Falk 2002, Boffi–Gastaldi 2002, Q2–P1 Stokes). V07 판은 매끄러운 사상이라 두 선택의 차이가 작다: `p=2 C^0 / P1`, `h=0.125`에서 `e_sigma_xx` 물리 `1.0165e-3`, 매개변수 `1.0014e-3`. 곡선 셀에서 두 공간이 다르다는 점은 시험으로 확인했다(매개변수 P1은 X의 1차식을 재현하지 못함, 오차 `> 1e-6`).
- **선형화(V07 = 선형 탄성)**: $u=0$에서의 일관 접선으로 한 번 푼다(`solve_linearized`). 쌍선형식은
  $\mu(\nabla u,\nabla v) + \mu(\nabla u^T,\nabla v) - \mu(\mathrm{div}\,u,\mathrm{div}\,v) + (\lambda+\mu)(\Pi\,\mathrm{div}\,u,\Pi\,\mathrm{div}\,v)$
  이고 응력은 $\sigma = \mu(\nabla u + \nabla u^T) - \mu\,\mathrm{div}\,u\,I + (\lambda+\mu)\,\Pi(\mathrm{div}\,u)\,I$ ($\Pi = I$이면 $2\mu\varepsilon + \lambda\,\mathrm{tr}\,\varepsilon\,I$). 이 $\sigma$는 $\mu/J\,B + \hat p\,I$의 $u=0$ 선형화이며($U'(1) = -\mu$, $U''(1) = \lambda+\mu$, $\Pi$는 상수 재현), 쌍선형식과 $a(u,v) = (\sigma, \nabla v)$ 관계로 일치하는 (이산 평형을 만족하는) 응력이다. $-\mu\,\mathrm{div}\,u$ 항은 사영되지 않는다: P0/P1 해에서 $(I-\Pi)\,\mathrm{div}\,u_h$는 체적 벌칙의 구속을 받지 않아 작지 않으므로(V07에서 이 항을 함께 사영하면 `e_sigma_xx`가 3–33 % 바뀐다, §8 M8) 이 항의 처리는 결과에 보인다.
- **구현**: Numba 셀 커널, `fbar.build_model`의 기하·적분점·셀→제어점 맵·CSR 패턴(node-pair scatter)을 import 재사용, `pypardiso` 직접법. `solve_static`(대변형 Newton)은 `fbar.solve_static`의 루프를 옮기고 두 가지를 바꿨다: (i) 일관 선형 예측자(직전 수렴 상태 접선 + 처방 변위 증분 lifting), (ii) 기본 `rtol = atol = 0`(증분 판정만). 근거는 §6.

굽힘 패치의 원리: P1이면 $\Pi\,\mathrm{div}\,u_{ex} = \mathrm{div}\,u_{ex}$ 이므로 정확해가 이산 방정식을 그대로 만족한다(이산 해 = 정확해). P0는 선형 체적 응력 $\lambda\,\mathrm{div}\,u = \nu c y$를 셀 상수로 잘라 $O(c\cdot$셀 높이$)$를 놓친다. 굽힘·아핀 패치는 $\Pi\,\mathrm{div}\,u = \mathrm{div}\,u$라서 $-\mu\,\mathrm{div}\,u$ 항과 사영의 구별력이 없다 — 이를 위해 위 두 응력 회복 시험을 추가했다(div u가 압력 공간 밖에 있는 장). 선형화 시험의 ν=0.3 선택 이유: 처방된 장에서는 $\mathrm{div}\,u = O(|\nabla u|)$이므로 ν=0.49999면 $\mu(\Pi\mathrm{div}\,u - \mathrm{div}\,u)$가 응력의 $O(\mu/\lambda) \approx 2\times10^{-5}$에 불과하다.

**V07 P1 대 P0 (측정값 고정 없음)**: 평균 응력 $p_{ex} = (1+\nu)(\sigma_{xx}+\sigma_{yy})/3$ (평면변형률 $\sigma_{zz} = \nu(\sigma_{xx}+\sigma_{yy})$). 회복 응력의 평균은 $\mathrm{tr}\,\sigma_h/3 = q_h - \tfrac{\mu}{3}\mathrm{div}\,u_h$, $q_h = (\lambda+\mu)\Pi\,\mathrm{div}\,u_h \in Q_h$이므로, 적분점 가중 $L^2$ 노름(그 안에서 $\Pi$가 직교 사영 = 최량 근사)으로 $e_p \ge \varepsilon_Q - \delta$, $\varepsilon_Q = \|p_{ex} - \Pi_Q p_{ex}\|/\|p_{ex}\|$, $\delta = \tfrac{\mu}{3}\|\mathrm{div}\,u_h\|/\|p_{ex}\|$ (정리). 시험은 (a) 두 해가 각자의 하한을 만족함(정리 — 오차 계산과 응력 구조의 검사), (b) **P1의 $e_p$가 P0 하한 $\varepsilon_0 - \delta_0$ 아래** — 셀 상수 압력을 쓰는 어떤 해도 이 격자에서 내려갈 수 없는 값을 P1이 밑돈다, (c) P0/P1 `e_sigma_xx` 비율이 세분화마다 증가(사영 차수 $O(h)$ 대 $O(h^2)$ → 비율 $\propto h^{-1}$)를 assert 한다. $\Pi_Q p_{ex}$는 시험 내 독립 `lstsq` 사영, $\mathrm{div}\,u_h$는 `fbar`의 `G_all`(S40 커널).

## 4. 어떤 조합이 잠기는가 (이산 inf-sup + 오차)

이산 inf-sup 상수 $\beta_h^2 = \lambda_{min}(B K^{-1} B^T)$ ($K$: 자유 DOF 벡터 $H^1$ 반노름 Gram, $B_{(c,k),(n,a)} = \sum_q w_q \Psi_{qk}\,\partial N_n/\partial X_a$, 정규직교 기저라 압력 질량 = I), V07 판·V07 Dirichlet 집합, 스크래치 계산. "null" = $B^T$ 영공간 차원(어떤 변위도 닿지 않는 압력 모드; 응축식에서는 구속을 만들지 않아 무해).

| `p=2 C^0` / P1 | ~8 | `1.231e-2, 1.210e-2, 1.160e-2` | 0 | `1.13e-2 / 3.66e-3` | 안정 |

- 최대 매끄러움 공간(`C^(p-1)`)은 셀당 면내 변위 DOF가 약 2개뿐이라 면내 P1 모드 3개(1, x, y)를 감당하지 못한다(`p=2 C^1`, `p=3 C^2`). 면내 P1만 쓰는 `(1, x, y)` 변형도 결과가 동일하다(`e_sigma_xx` 30.5): 이 평면변형률 문제의 이산 해는 z에 무관해 z-모드가 비활성이므로 P1과 P1xy의 결과가 모든 출력 자릿수에서 같았다.
- `p=3 C^1 / P1`: $\beta_h$가 h에 따라 천천히 감소(h=0.5→0.25에서 16 %), σ 오차가 압력 성분 지배(`h=0.25` 압력 `4.90e-3`, 편차 `9.7e-4`)이고 원공 첫 셀 행(15 %)보다 그 밖의 내부 셀들(약 77 %)에 퍼져 있다. $\nu=0.3$ 대비 오차 2.13배(`4.94e-3` vs `2.32e-3`), σ 기울기 `1.228 -> 1.150` (`h=0.5, 1/3, 0.25`, DOF 7,350 / 15,300 / 26,130). `C^(p-2)` 공간이 P1 압력과 짝지을 수 있는 경계에 있음을 보여준다.
- P2의 null 모드(셀당 1개 또는 2셀당 1개)의 정체는 확인하지 않았다(u_z ≡ 0 구속과 관련된 두께 방향 모드로 추정, 미검증).

## 7. plan 목표 2.2에 대한 결론

1. **P1-disc 압력은 2.2 목표의 해법이 아니다.** 안정한 p=2 공간(`C^0`)에서 σ 기울기는 `1.63 -> 1.85`로 이론 상한 2를 향하고, V07 원래 공간(`C^1`)에서는 잠긴다. 다만 P1-disc(`p=2 C^0`)는 P0 대비 같은 격자에서 σ 오차를 4–12배, 같은 DOF에서 3.4배 줄이므로 **응력 정확도 개선책**으로는 유효하다.
2. p=2 변위에서 σ의 점근 차수는 2가 상한이다. Coreform의 `2.385` (p=2, 연속 압력 + VMS)는 `h=0.5–0.125` 구간의 전점근 기울기로 해석된다. 따라서 plan의 `2.2`는 p=2 변위에 대해서는 전점근 거동에 기대는 목표다.
3. **`h = 0.5, 1/3, 0.25`에서 목표 기울기를 만족한 불연속 압력 조합은 `p=3 C^0 / P2-disc`**이다(`slope_sigma_xx = 2.413`, `slope_u = 3.391`, 측정한 두 v07.json 레벨 `0.5`, `0.25`에서 게이트 상한 대비 수십–수백 배 여유). v07.json 스윕(`0.5 / 0.25 / 0.125`)으로는 측정하지 않았다: 비용은 셀당 DOF 증가(h=0.25에서 53,835 DOF, 1.0 GB)이며 h=0.125(약 4 GB)는 이 PC에서 실행 불가.
4. 권고(결정은 사용자/Phase 계획에 맡김): (a) V07 기울기 게이트를 유지하려면 `p=3 C^0/P2`를 V07 정식 경로 후보로 두거나, (b) p=2를 유지하려면 기울기 기준을 source doc 기준(`> 0.5`) + "점근 차수 2 근접"으로 재정의. `mixed_p1`은 아직 `methods`/파이프라인에 연결하지 않았다(이 과제 범위 밖).
