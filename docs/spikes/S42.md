# S42 Phase 5 V07 (Kirsch 무한 평판 원형 구멍, ν=0.49999) 선행 조사 (2026-11-19)

## 질문
1. Kratos 내장 혼합 요소(`SmallDisplacementMixedVolumetricStrainElement3D4N`, `SmallDisplacementMixedStrainElement3D4N`)가 `p=2` `QuadraturePointGeometry` (`ν=0.49999`)에서 초기화·해석이 가능한가?
2. `wht_iga.analyses.fbar` (수정 없이 읽기 전용 재사용)는 body-fitted 사상(mapped) 1/4 평판 Kirsch 문제(`0 <= x,y <= 4`, `r >= 1`, `t = 0.25`, `E = 100000`, `ν = 0.49999`, `T = 10`)를 직접 풀 수 있으며, Kratos 표준 변위 요소(`SmallDisplacementElement3D4N`) 대비 locking을 얼마나 해소하는가?

## 결론 요약
1. **Check A (Kratos 혼합 요소 QP 호환성 불가):**
   - `SmallDisplacementMixedVolumetricStrainElement3D4N`: `p=2` QP geometry에서 `Initialize()` 중 Access Violation(`returncode=3221225477`, `0xC0000005`)으로 프로세스 종료 (S13의 `p=1` 결과와 동일).
   - `SmallDisplacementMixedStrainElement3D4N`: `Initialize()`는 통과(`INIT-OK`)하나, `strategy.Solve()` 중 Access Violation(`returncode=3221225477`)으로 프로세스 종료.
   - 따라서 Kratos 내장 혼합 요소는 `QuadraturePointGeometry` 경로에서 사용 불가하다.
2. **Check B (`fbar` body-fitted Kirsch vs Kratos 표준 변위 요소, `ν=0.49999`):**
   - `fbar.build_model`은 `cp[idx]`로부터 일반 야코비안 `Jg = dX/dξ` 및 내부 중복 매듭(`v=0.5`의 `C^0` 코너)을 이미 지원하므로, `MappedQuarterPlate` (`p=2`, `(4,4)` 코너만 `C^0`, 나머지 `C^1`)를 코드 수정 없이 그대로 해석한다.
   - `h0=0.5`, `h1=0.25` 모두 체적 오차 `<= 3.3e-8` (게이트 `0.1% = 1e-3` 충족), `e_u`·`e_sigma_xx` 모두 G5 오차 게이트를 크게 여유 있게 통과한다. 반면 Kratos `SmallDisplacementElement3D4N`은 `ν=0.49999`에서 심각한 volumetric locking을 보인다(`h1=0.25` 기준 `e_sigma_xx = 2694%`).
