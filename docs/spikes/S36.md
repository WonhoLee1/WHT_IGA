# S36 THB 파이프라인 본연결 (Track H Phase 2, Go 판정)

## 질문
`run_linear`에서 THB 적응 세분화를 쓸 수 있는가 (UNSUPPORTED_REFINEMENT 해제)?

## 결과: 예. 4/4 통과 (3.00 s).
- `tests/kratos_spikes/test_thb_pipeline.py`:
  단축 exact (1e-9), 굽힘 3% 이내, roundtrip, 명시적 set-거부.
- Go 판정 근거: 단축 1e-9, 굽힘 3.8e-4 수준 (축소 케이스).

## 구현 (공유 모듈 최소 가산, 기존 경로 무수정)
- `validate.py`: `JobSpec.thb_refinement: dict | None` 필드 + from_json
  (shape: level 1..5 / balance / boxes / spheres).
- `pipeline.py`: `_run_linear_thb` 신규 + 분기 3줄. uniform 경로 무수정.
- 미지원은 명시적 `ValidationError`: named-set, pressures, gravity,
  OUT cells, 부분-component bcs.
- 컴파일러 가드(`compiler.py` UNSUPPORTED_REFINEMENT) 손대지 않음 —
  User API 계약 유지, `test_user_api.py` 무변경 통과.
- `id_table.allocate_*` 계열 사용 (수동 +100 오프셋 아님).

## 남은 과제
- `_write_outputs` (mesh db/vtu/probe json) THB 미연동 — output_dir 지정 시
  스킵 (로그 경고 후). 정식 출력은 후속.
- sphere 영역 E2E 검증은 G3-05(box) 통과로 갈음, sphere 단독 케이스 추가 예정.
