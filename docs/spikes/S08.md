# S08 pressure / traction / follower loads

- 질문: `LoadCondition` PRESSURE/SURFACE_LOAD/FOLLOWER가 표면 적분점 기하에서 총하중을 정확히 적분하나? 부호 규약은? (v2 §5.8 S08)
- 결과: 예
- 근거 (`tests/kratos_spikes/test_s08_pressure_load.py`, 3 passed; 단위 정육면체 1셀 p=1, E=1000, 밑면 고정, 윗면 하중, SkylineLU):
  1. `PRESSURE = 2.0` → 밑면 반력합 z = -2.000000000000 (오차 < 1e-12). 부호 규약: 양의 PRESSURE는 외향 법선 방향으로 민다 (윗면에서 인장 방향, +z). 즉 traction = +p·n_out.
  2. `SURFACE_LOAD = (0,0,-3)` → 반력합 z = +3.000000000000 (오차 < 1e-9). 주어진 트랙션 벡터 그대로 적분.
  3. `PRESSURE_FOLLOWER_LOAD = 2.0` (E=1e6, move_mesh) → 반력합 z = -1.999996880001. dead-load 대비 상대차 1.56e-6 (미소변형 follower 보정, 물리적으로 타당).
  - 변수 위치: PRESSURE는 core (`KM.PRESSURE`), SURFACE_LOAD는 SM, PRESSURE_FOLLOWER_LOAD는 IgaApplication.
- 환경: Python 3.12.16 (whtiga), Kratos 10.4.3 소스빌드 (`E:\kratos-build\install`), 날짜 2026-11-14
- 결론과 영향: 하중 경로 성립. 총하중 압력(p = F/Σw)은 면적합이 정확하므로 그대로 쓴다. follower 부호도 dead-load와 동일. R1 유지.
