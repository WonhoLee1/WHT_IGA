# S30 E03 축소판: 셀 그룹 열변형률 + 온도 의존 E·항복응력 + 열 step 구동 (S28 경로)

## 질문
S28의 초기 변형률 우회를 E03에 쓸 수 있는 모듈로 만들 수 있을까요?
- 셀마다 다른 온도
- 온도 의존 E·항복응력
- 열 step 3개(가열·유지·냉각)

## 결과: 예. 1D 해석해와 기계 정밀도로 일치합니다.
셀 내부 재료 경계는 아직 다루지 못합니다. 경화(hardening)는 S42에서 추가했습니다.

### 모듈 `wht_iga/analyses/thermal_plasticity.py`
- `TempTable`: 온도에 대한 구간 선형 표입니다. 범위 밖은 끝값으로 고정합니다(Abaqus 동작).
- `ThermoMaterial`: E(T), ν, 할선 α(T), 0점 온도, σ_y(T)를 담습니다. `None`이면 열탄성(유리)입니다.
  - 열변형률은 ε_th = α(T)(T − T_zero) − α(T_init)(T_init − T_zero)입니다.
  - Abaqus `*EXPANSION, ZERO`와 초기 온도장의 의미를 따르므로, 초기 상태는 무응력입니다.
- `CellThermalGroups`: (재료, 모든 열 상태의 반올림 온도 이력)이 같은 요소를 한 그룹으로 묶습니다.
  - 그룹마다 부분 모델 파트 1개와 `Properties` 1개를 **한 번만** 만들고, 전 이력에 재사용합니다.
  - level마다 그룹당 `SetInitialStateProcess3D` 1회와 E·σ_y `SetValue`만 수행합니다.
  - 반올림 칸의 폭은 quantum이고 그룹 온도는 칸 중심이 아니라 구성원 평균입니다. 그래서 셀 온도 오차 한계는 quantum/2가 아니라 quantum 미만입니다(시험 (i): 0.933 quantum).
- `run_thermal_steps`: `nonlinear.run_load_stepping` 위에서 동작합니다.
  - level s ∈ [k, k+1]이면 열 상태 k와 k+1을 선형 보간합니다.
  - 전략은 하나만 씁니다. 수렴한 증분마다 `on_converged(level)`를 부릅니다(전략 프록시의 `FinalizeSolutionStep`).
- `e03_materials_initial_yield`: Coreform TSV 표로 E03의 세 재료를 만듭니다.
  - 이름대로 **초기 항복 완전소성 근사**입니다(아래 한계 참고).

### Kratos 소스에서 확인한 사실 (읽기 전용)
- 갱신한 E가 반영됩니다. 다음 법칙들이 매 호출마다 `Properties`에서 탄성 행렬을 다시 만들기 때문입니다.
  - `LinearElastic3DLaw`(`ElasticIsotropic3D`)
  - 일반 소성 법칙(`CalculateElasticMatrix`)
- 따라서 응력은 Abaqus와 같은 전량형 σ = D(T):(ε − ε_th − ε_p)입니다.
- `LinearElastic3DLaw`도 `InitialState` 변형률을 뺍니다. 그래서 유리의 열탄성 경로가 됩니다.
- 유한변형 J2(`FiniteStrainIsotropicPlasticity3DVonMisesVonMises`)의 구조는 다음과 같습니다.
  - Hencky 변형률(B = FFᵀ)에서 초기 변형률을 빼고, Kirchhoff 응력으로 항복을 판정합니다.
  - 소변형·유한변형 J2 모두 0 < F ≤ 1e-4·σ_y이면 탄성으로 처리합니다.
  - 그래서 시험 경로가 이 띠 밖에 있는지 검사했습니다.
- `Element.Properties`는 setter가 바인딩되어 있습니다. 요소별 Properties 재지정이 가능합니다(전략 `Initialize` 전).
  - `Geometry.SetValue`는 여전히 바인딩되어 있지 않습니다.

## 한계
- **온도는 요소 안에서 일정합니다.** 처리 과정이 요소의 모든 적분점에 같은 상태를 씁니다.
  - 요소 = 셀이므로, 셀 안의 온도 구배는 셀 평균으로 처리하거나 셀을 세분해야 합니다.
  - E03은 균일 온도라 문제가 되지 않습니다.
- **재료도 요소 안에서 하나입니다.**
  - E03의 유리·금속 경계는 배경 셀을 가릅니다.
  - 그래서 요소를 (셀 ∩ 재료 영역) 단위로, 영역별 적분점으로 만들어야 합니다. `bimaterial.py`가 해석적 형상에서 쓰는 방식입니다.
  - 하나의 스플라인장을 공유하므로(완전 접합) Nitsche 결합은 필요 없습니다.
- **경화는 S42에서 해결했습니다.** 이 문서의 시험은 완전소성(`HARDENING_CURVE = 3`)입니다.
  - `ThermoMaterial(hardening=HardeningTable(...))`이면 그룹 Properties가 `HARDENING_CURVE = 6`(`CurveDefinedByPoints`, PEEQ 격자)을 씁니다.
  - 일반 법칙은 소성 소산 κ = W_p·l_c/G_f로 경화하지만, 점 구간에서는 S가 PEEQ에 선형인 곡선과 정확히 같고 l_c·G_f가 약분됩니다(메시 크기 무관).
  - 남는 두 결함(반환 반복의 W_p 과잉 누적, 온도 의존 곡선을 일(work)로 읽음)은 PEEQ 동기화로 없앴습니다(`commit`·`apply`).
  - E03 표는 `e03_materials`(Alloy 52 선형 1924 MPa, 304L 12점 × 7온도)입니다. `e03_materials_initial_yield`는 비교용으로 남겼습니다.
  - 남은 오차(반환 허용 1e-4·S, 증분 내 과잉, 볼록 꺾임점 과반환)와 비용은 S42를 참고하세요.
  - `SmallStrainJ2Plasticity3DLaw`는 `InitialState`를 쓰지 않습니다(소스에 참조 0건). 그래서 여전히 일반 법칙 경로입니다.
- **유리:** `LinearElastic3DLaw` + E(T)는 검증했습니다.
  - TL에서 유리는 Green–Lagrange(SVK), 금속은 Hencky를 씁니다. 두 측도가 섞이지만, 차이는 O(ε²)라 E03 수준에서는 무시할 만합니다.
  - 점탄성·구조 이완은 E03 범위 밖입니다.
