# S07 surface quadrature-point geometry

- 질문: `SurfaceInNurbsVolumeGeometry(volume, Triangle3D3)` + 사용자 적분점의 `DeterminantOfJacobian`이 면적 요소이고 `Normal`이 삼각형 방향과 일치하나? (v2 §5.8 S07)
- 결과: 예 (단, 기하 1개가 아니라 적분점당 1개씩 생성됨 — 아래 근거 4)
- 근거 (`tests/kratos_spikes/test_s07_surface_geometry.py`, 3 passed):
  1. 단위 정육면체 윗면(z=1) 삼각형 2개, 3점 규칙: 면적합 Σw·detJ = 1.000000000000000 (p=1, p=2 동일, 허용오차 1e-13).
  2. 법선: 외향 권선 → n = [0, -1.1e-16, 1.0], 뒤집힌 권선 → n = [1.1e-16, -1.1e-16, -1.0]. 법선 부호는 삼각형 권선을 따름 (외향 = +z).
  3. `IntegrationPointsNumber()` = 적분점 수와 일치 (규칙당 기하 1개가 아니라 점당 1개).
  4. v2 §5.4 가정("표면 적분점 기하 1개")과 다름: `SurfaceInNurbsVolumeGeometry::CreateQuadraturePointGeometries` 오버라이드(`surface_in_nurbs_volume_geometry.h` l.278)는 적분점마다 기하 1개씩 만든다 (각자 nonzero 제어점 집합 보유). 조건은 적분점 기하마다 1개씩 붙이면 된다 (S08/S09에서 실증).
  5. Python 바인딩에 `Geometry.IntegrationPoints()` 접근자가 없어 가중치는 호출자가 준 값을 그대로 쓴다 (S08 총하중 적분으로 pass-through 실증).
