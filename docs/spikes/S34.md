- `auto` → IGA 존재 시 `penalty_spring` (build_tie 선천 매핑, S34 확인).
- penalty 정확도 = 1/beta 법칙 (3 decade 실측: 6.25e-6 → 6.25e-7 → 6.24e-8).
  테스트는 beta 명시: uniaxial hybrid_auto beta=1e5, couplings beta=1e6.
- mortar_l2: 기계 정밀도 (4.5e-18). 정확도가 필요하면 mortar 사용.
- barycentric: O(h) 계면 정합 (nc=2 팁 rel 8.8e-4/1.66e-3 → nc=4 절반).
  가중치 재현 5e-20·강제 0·노드 순서·커버리지 전부 정상 확인, p=1/hex8 정확
  (1.7e-18) → 기구는 정상, p=2 pointwise 전달이 계면에서 O(h).
  게이트 2e-3 + 특성 문서화, exactness 필요시 mortar 권장.
  (8 probe로 1차 원인 미특정 — 가중치·강제·순서가 모두 정상이므로
