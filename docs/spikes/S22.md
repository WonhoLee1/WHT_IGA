# S22 `ContactStructuralMechanicsApplication` 프로세스 및 표면층 결합 검증

- 질문: `ContactStructuralMechanicsApplication`의 `mesh_tying_process`(mortar)와 `penalty_contact_process`가 스프링(`SpringDamperElement3D`) 또는 `LinearMasterSlaveConstraint`로 스플라인에 결합된 표면층 삼각망 노드에서 동작하는가?
- 결과: **아니오** (`mesh_tying_process` 및 `penalty_contact_process`는 IGA `QuadraturePointGeometry` 모델파트에서 초기화 실패; 대안인 `LinearMasterSlaveConstraint` + `SpringDamperElement3D` 표면층 tie는 정상 동작)
- 근거 (`tests/kratos_spikes/test_s22_surface_contact.py`, 4/4 통과 — 실패 원인 3건 실측 확인 + 대안 1건 통과):
  1. `mesh_tying_process` on IGA `ModelPart`: `ExecuteInitialize()` → `SearchBaseProcess._interface_preprocess` → `InterfacePreprocessCondition::CheckOnTheFace`가 `Structure` 내 `QuadraturePointGeometry` 요소에 `Geometry::GenerateFaces()`를 호출하면서 `RuntimeError: Error: Calling base class GenerateFaces method instead of derived class one`로 실패.
  2. `penalty_contact_process` on IGA `ModelPart`: `PenaltyContactProcess`가 `ALMContactProcess` → `SearchBaseProcess`를 상속하므로 동일 경로(`InterfacePreprocessCondition::CheckOnTheFace` → `Geometry::GenerateFaces()`)에서 동일 `RuntimeError`로 실패.
  3. 요소 없는 별도 표면 `ModelPart`(`ContactSurf`)에서 `mesh_tying_process` 우회 실행 시: `InterfacePreprocessCondition::CheckAndCreateProperties`가 부모 솔리드 요소를 찾지 못해 `RuntimeError: Error: It was not possible to add a property`로 실패.
  4. **대안 표면층 tie 검증** (표면 `Triangle3D3` 노드를 `LinearMasterSlaveConstraint`로 스플라인 제어점에 결합 + 계면 `SpringDamperElement3D` $k=10^{10}$로 두 1-cell 블록 적층 tie, 상단 하중 $F_z=-2.0$):
     - 단일 `1x1x2` 블록 대비 상면 평균 변위 차: `uz_top_tied = -0.003811518` vs `uz_top_mono = -0.003811518` (`diff = 5.220e-11`).
     - 계면 점프 최대 `jump_z = 5.000e-11`, 밑면 반력합 `sum_Rz = 2.000000002` (오차 `1.62e-9`).
- 환경: Python 3.12.16 (`whtiga`), Kratos 10.4.3 소스빌드 (`E:\kratos-build\install`), 2026-11-14
- 결론과 영향: `mesh_tying_process`와 `penalty_contact_process` Python 고수준 프로세스는 `InterfacePreprocessCondition`이 `Geometry::GenerateFaces()`와 부모 솔리드 요소를 전제하므로 IGA `QuadraturePointGeometry` 모델파트에 그대로 적용할 수 없다. 접촉/tie 구현 시 (a) 표면층 + `SpringDamperElement3D`/직접 페널티 접촉 요소 경로를 쓰거나, (b) `InterfacePreprocessCondition` 없이 mortar `PairedCondition`을 직접 생성·탐색하는 경로가 필요하다.
