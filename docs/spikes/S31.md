## 정식화 (`wht_iga/analyses/contact.py`)
기존 `tied_surface_layer`, `paired_gap_z`는 그대로 유지하고 아래 5종을 추가했습니다.

1. **스플라인 표면 기저 평가 (`bspline_basis_matrix`, `expand_vector_basis`)**
   - `wht_iga.grid.bspline`의 `find_span`·`basis_1d`로 임의 물리 좌표 `(M, 3)`에서 스칼라 B-스플라인 기저행렬 `B_scalar` `(M, n_ctrl)`을 CSR로 직접 조립합니다(단위 분할 `∑_I N_I(x) = 1`을 `1e-14` 이내로 만족).
   - `expand_vector_basis(B_scalar, 3)`은 `kron(B_scalar, I_3)`으로 `BoxSpline` 자유도 순서(`3*I + d`)에 맞는 `(3M, 3 n_ctrl)` 벡터 기저를 생성합니다.

2. **경계면 복합 Gauss-Legendre 적분 (`sample_box_face_gauss`)**
   - 경계면 `axis` (`side ∈ {0, 1}`)의 각 셀을 선택적 활성 창 `bounds = ((u_lo, u_hi), (v_lo, v_hi))`으로 절단하고, `n_sub × n_sub` 소구간과 `n_gp`차 `leggauss`를 적용해 정확한 물리 가중치 `w_q = jac_a · jac_b · w_a · w_b`와 `(X_q, w_q, B_scalar)`를 반환합니다.

3. **강체 장애물 (`RigidSphereObstacle`, `RigidPlaneObstacle`)**
   - 강체 구 `(center, R)`: 변형 위치 `x_q = X_q + B_scalar @ u_ctrl`에서 `d = x_q - c`, `r = ||d||`, 구 바깥 법선(블록 진입 방향) `n = d / r`, 법선 간격 `g_n = r - R`, 곡률 계수 `curv = g_n / r`를 계산합니다.
   - `g_n < 0`인 활성 적분점의 잔차 항은 `t_res = w_q · ε_n · g_n · n`이며, 평형 방정식 `K_f u - f_ext + B_free^T t_res = 0`을 풉니다(블록이 구에 가하는 합력 `F_on_obstacle = ∑ t_res`).

4. **일관 접선 강성 및 SPD 폴백 (`solve_ssn_contact`)**
   - 수직 접촉 일관 접선: `k_n = w_q · ε_n · [n ⊗ n + (g_n / r)(I - n ⊗ n)]`.
   - **발견된 3-주기 진동과 처방**: `u = 0`에서 `δ = 0.1`을 바로 풀 때, 초기 관입(`g_n / r ≈ -0.25`)의 음의 곡률 항이 접선 방향을 연화시켜 블록이 구 아래로 과도하게 내려가(`n_act → 0` → `u = 0` 복귀) 3-주기 비수렴을 유발했습니다(`h1, ε_n = 10^9`: 19 → 5 → 0 → 19).
   - 따라서 활성 집합이 안정되고 잔차 노름 `rnorm < 0.1`인 수렴 영역에서만 곡률 항을 활성화하고, 이탈 시 즉시 SPD 접선(`n ⊗ n`)으로 폴백합니다.

5. **Coulomb 마찰 (`μ > 0`)**
   - 직전 스텝 상태 `slip_state = (x_prev, t_t_prev)`와 장애물 증분 변위 `obstacle_disp`로 접선 상대 변위 증분 `Δu_t = P_t (x_q - x_prev - Δx_obs)`를 구하고, Trial 접선력 `t_trial = P_t t_t_prev + ε_t Δu_t`에 방사 복귀(`||t_t|| ≤ -μ ε_n g_n`)를 적용합니다.
   - Slip 분기 일관 접선 `w_q [ε_t (cap/||t_trial||)(P_t - d_hat ⊗ d_hat) - μ ε_n (d_hat ⊗ n)]`은 비대칭이며 유한차분(FD) 검증 상대오차 `7.70e-6`(`dv ~ 1e-7`)으로 일치했습니다. Stick/slip 비평활 경계 통과를 위해 `μ > 0`일 때 Armijo 잔차 백트래킹(`α = 1, 1/2, ..., 1/64`)을 적용했습니다.

## 실측 (`tests/kratos_spikes/test_p5_v08_r0_ssn.py`, 4 passed)

### 1. 평면 강체 펀치 (`test_flat_rigid_punch_p2_analytic`)
- 조건: `[0, 1]³` (`2×2×2`, `p = 2`), `E = 1000`, `ν = 0.3`, 측면 자유 단축 응력, `δ = 0.05`, `ε_n = 10^8`.
- 결과: 1회 Newton 수렴, `F_N = 49.999500 lbf` (직렬 스프링 해석해 `49.999500`과 `1e-11` 이내, 강체 극한 `50.0` 대비 상대오차 `1.0e-5 = O(1/ε_n)`). 표면 B-스플라인 변위 `(u_x, u_y, u_z)`가 3D 포아송 해석해와 `1e-11` 이내 일치, 면적 적분 `∑ w_q = 1.0`.

### 2. 단방향 분리 (`test_unilateral_sphere_separation`)

- **성능**: `h0` 조립 `0.27 s` · 해법 `0.4~0.6 s`; `h1` 조립 `1.50 s` · 8증분 해법 `3.1~7.6 s`; `h2` (`23,460` DOFs) 전체 `25.93 s`, 피크 메모리 `< 0.6 GB`.

  - `h1 → h2` (`ε_n = 1e9`: `533,322 → 520,736 lbf`)에서 메시 세분화에 따라 하중이 감소하며, 강체 접촉 극한에서 R0 유한 블록(`H = 2.0 in` 바닥 고정)은 반무한 공간보다 약 8~13% 더 단단합니다(별도 탐침에서 `H = 4.0 in`로 깊이를 2배 늘리면 `h1, ε_n = 1e10` 기준 `565,586 → 524,114 lbf`로 하강).

  - 또한 `h0 = 0.5`(`h > 2a`)에서 `ε_n ≥ 1e9`일 때 단일 2차 셀 내부의 과구속으로 활성 점이 줄어들며 과경화되므로, V08 본 해석에서는 최소 `h1 = 0.25` 이하(`a ≈ h`) 및 적절한 페널티 `ε_n ~ (5..20) E/h` 선택이 중요합니다.
