## 정식화 (`wht_iga/analyses/contact.py`)
기존 함수·클래스를 보존하고 Track D 검증 보완 2건(1: `bspline_basis_matrix`에서 `basis_1d` 중복 `find_span` 제거 후 `ders_basis_funs(..., 0, ...)[0]` 직접 호출, 2: `solve_ssn_contact` Armijo 백트래킹에 `||du|| > 0.0` 가드 추가)과 함께 변형체-변형체 SSN 접촉 3종을 추가했습니다.

1. **물리 삼각형 표면 Gauss 적분 (`sample_surface_triangles_gauss`)**
   - `wht_iga.kratos_backend.surface.triangle_quadrature(order)`의 Dunavant 규칙으로 슬레이브 물리 삼각형 `(nodes, tris)` 위 적분점 `X_s (M, 3)`, 정확 면적 가중치 `w_q = 2 · area · ref_w` (`∑ w_q = ∑ area`), 슬레이브 B-스플라인 기저 `B_s (M, n_ctrl_s)`를 생성합니다.

2. **변형체 BoxSpline 경계면 최근접점 투영기 (`DeformableBoxFaceMaster`)**
   - 마스터 `BoxSpline`의 경계면 `(axis, side)`와 현재 제어점 변위 `U_m (n_ctrl_m, 3)`에 대해, Numba 커널(`_project_box_face_njit`)로 각 슬레이브 변형점 `x_s`의 최근접 매개변수 `(a*, b*) ∈ [lo_a, hi_a] × [lo_b, hi_b]`를 1차 미분 `ders_basis_funs(..., 1, ...)`과 Gauss-Newton 헤시안 `J^T J` 기반 2D 투영 Newton으로 탐색합니다.
   - 마스터 바깥 법선 `n_m = orient · (∂x_m/∂a × ∂x_m/∂b) / ||...||`과 부호 있는 간격 `g_n = (x_s - x_m) · n_m` (`g_n < 0`이면 관입), 그리고 `(a*, b*, fixed)`에서의 마스터 기저 행렬 `B_m (M, n_ctrl_m)`을 반환합니다.
   - 최근접점 정상성 `(x_s - x_m) · ∂x_m/∂a = (x_s - x_m) · ∂x_m/∂b = 0`에 의해 `δg_n = n_m · (B_s δu_s - B_m δu_m)`가 정확히 성립합니다.

3. **연성 변형체 SSN 해법 및 대류 접선 미끄럼 (`solve_deformable_ssn_contact`)**
   - 결합 계통 `K_sys = block_diag(Kf_m, Kf_s) + B_pair^T K_blk B_pair` (`B_pair = [-B_m_free, B_s_free]`)와 잔차 `f_{c,m} = -B_m^T t_res`, `f_{c,s} = +B_s^T t_res`를 조립하고 `_solve_linear_step`으로 풉니다. 여기서 `t_res = w_q (t_n + t_t)`는 슬레이브가 마스터에 가하는 합력입니다.
   - **대류 접선 미끄럼 증분(`μ > 0`)**: 슬레이브 적분점 `q`의 물질 변위 증분 `(x_s - x_s_prev)`에서 현재 접촉 중인 마스터 표면 물질점 `ξ_curr = (a*, b*)`의 라그랑주 변위 증분 `B_m(ξ_curr)(U_m - U_m_prev)`을 빼 `Δu_rel = (x_s - x_s_prev) - B_m(ξ_curr)(U_m - U_m_prev)`를 계산합니다. (`x_m(ξ_curr) - x_m(ξ_prev)`를 쓰면 강체 미끄럼이 상쇄되므로 부적절합니다.)
   - 이후 `P_t = I - n_m ⊗ n_m` 투영, Coulomb 방사 복귀(`||t_t|| ≤ -μ ε_n g_n`), 비대칭 일관 접선, Armijo 잔차 백트래킹(`need_tangent=False` 최적화 포함)을 적용합니다.

4. **트리밍 강성 추출 및 Dirichlet 분할 (`_assemble_kratos_partitioned_stiffness`)**
   - `build_trimmed_table(..., q=4, cache_dir="off")`와 `SmallDisplacementElement3D4N` (`CUT`: `qp_table`, `IN`: 표준 Gauss, `OUT`: `ghost_alpha = 1e-8`)을 모델링하되 Kratos 노드를 Fix하지 않고 `builder.BuildLHS`로 비구속 전역 강성 `K_full`을 추출한 뒤, `inactive_ctrl_mask`·대칭/바닥 고정(`zero_mask`)과 절단면 변위 구속(`presc_mask`)으로 `(K_ff, K_fp, K_pf, K_pp)`를 메쉬당 1회 분할합니다.
   - 각 하중 증분에서 `f_ext = -(K_fp @ u_presc)`를 부과하고 `R_presc = K_pf @ u_free + K_pp @ u_presc + f_c_s_full[presc_mask]`로 계면 하중과의 전역 평형을 직접 검증합니다.
