# S40 E04 Cook: Numba 평균 팽창 F̄/P0로 G5 1 % 게이트 통과 (2026-11-19)

## 질문
E04(ν = 0.49999, TL Neo-Hookean) 1 % 게이트에 C++ U/P 요소가 꼭 필요한가?

## 결과: 아니오. Numba F̄/P0(`wht_iga/analyses/fbar.py`)로 통과.
- 정식화: Simo–Taylor–Pister 평균 팽창. 셀마다 J̄ = ∫J dV / V, 체적 에너지 U(J̄), 압력 P0는 닫힌 식으로 응축.
  Coreform E04의 U(p)/P(0) 구조와 같다(`e04.json` formulation). 단, 변위 연속성은 최대(C^(p-1))이고 Coreform은 C^(p-2).
- 하중: 오른쪽 면 균일 전단 traction 6.25 N/mm²(합력 191.516 N), 각 B-spline의 ∫N ds로 만든 정확한 등가하중. u_z 전체 고정(e04.json).

- p=1은 아래에서, p=2는 위에서 수렴한다. p=1 Richardson 극한 약 6.987(기준 대비 −0.03 %).
- p=2 관측 수렴 차수 약 1.1(모서리 특이점). 기준값 6.98946은 두 계열 사이에 있다.
- 하중 분배에 민감: p=2에 Greville 집중하중을 쓰면 모서리 절점 하중이 1/4h(정확값 1/3h)로 줄어 8×8에서 +0.52 %가 나온다. p ≥ 2에는 정확한 등가하중만 쓴다.

### 변경 (`fbar.py`)
- CSR 패턴을 노드 쌍 단위로 만든다(`_csr_pattern`, `node_pos[c, I, J]`). 이전 DOF 쌍 단위 `coo2csr` map보다 1/9 크기. 결과 행렬은 같다(아래).
- QP 데이터(G, W)는 `G_all`/`W_all` 한 벌만 둔다(셀 dict는 view).
- 셀 → span은 셀 중점의 `find_span`, first_cp = span − p(기존 유지). 내부 매듭 중복도 1..p(C^(p−1)..C^0)를 축별·매듭별로 섞어도 된다. 이전 식 span = ci + p는 최대 연속성에서만 맞다.

### 검증
- 밀집 vs 희소(p=2 C^1, p=2 C^0, p=3 C^1 다셀, 임의 상태): R, K 최대 차 **0.0**(비트 동일). 시험 허용치 1e-13.
- 이전 DOF 쌍 map(커밋 f0ec241) vs 노드 쌍 map: indptr·indices·data 모두 동일. 24×24×2 C^0(36,015 DOF, 1,152셀)에서 `build_model` 최대 메모리 389 → 205 MiB, 유지 메모리 141 → 71 MiB.
- Cook p=2 16×16 C^1 u_y: Pardiso 7.0380574142902, SuperLU 7.0380574142901, 밀집 경로 7.0380574142901(서로 ≤ 1.2e-15). 위 표의 7.03806과 상대차 3.7e-7.
- C^0 독립 기준: 2D Lagrange Q9/P0 평균 팽창 코드(시험 파일 안 별도 구현). Bernstein C^0 p=2와 Q9는 같은 공간이고 해가 z에 무관하다. 선형(u=0 접선) 팁 u_y가 1e-9 이내로 같다(시험: n=2, ν=0.3; n=3, ν=0.49). ν=0.49999 4/8/16에서도 12.408627 / 10.540784 / 9.364614로 표시 자리까지 같다.

### Cook p=2: C^0(Coreform U(p, C^(p−2))) vs C^1
ν = 0.49999, 정확한 등가하중, u_z 전체 고정, `n_steps=10`, Pardiso. 게이트 시험과 같은 설정(`_cook_case`).

| 격자 | C^1 u_y | 오차 | DOF | 해석 시간 | C^0 u_y | 오차 | DOF | 해석 시간 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 4×4 | 7.37756 | +5.55 % | 324 | 4.1 s | 9.14585 | +30.9 % | 729 | 16.9 s |
| 8×8 | 7.14649 | +2.25 % | 900 | 5.0 s | 7.96336 | +13.9 % | 2,601 | 22.7 s |
| 16×16 | 7.03806 | +0.70 % | 2,916 | 18–40 s | 7.62193 | +9.05 % | 9,801 | 73.9 s |

- 시간은 다른 에이전트와 CPU를 나눠 쓴 측정(부하 100 %)이라 약 2배 흔들린다. 16×16 C^1은 같은 해를 18 s와 40 s에 냈다. 밀집 경로는 356 s.
- Newton: C^1 11–12 증분 / 65–86 반복, C^0 36–41 증분 / 317–342 반복. C^0 4×4는 `n_steps` 10과 40에서 상태 차 1.3e-12 → 같은 평형점.
- 선형(u=0 접선)도 같은 경향: C^1 4/8/16/32 = 8.6586 / 8.3814 / 8.2331 / 8.1565, C^0 = 12.4086 / 10.5408 / 9.3646 / 8.7355. Newton 문제가 아니라 이산화 자체의 성질이다.
- 해석: p=2 C^0 + 셀당 P0는 Q9/P0와 같다. 셀당 평면 변위 DOF 약 8개에 압력 제약 1개(C^1은 약 2개)라 비압축 제약이 약해 너무 유연하다. 위에서 느리게 수렴한다(기준값 대비 관측 차수 1.15 → 0.62).
- 결론: p=2 C^0은 16×16에서 1 % 게이트를 못 넘는다(+9.05 %). C^0 게이트 시험은 넣지 않았다. 넣는다면 6.98946 ± 1 %로만 판정한다(측정값 고정 금지). 게이트는 C^1 유지.
- 열린 질문: Coreform U(p, C^(p−2))/P(0)이 6.98946을 낸 p·격자는 모른다(e04.json `mesh_sweep.status = unknown`). e04.json의 "fine pressure cell" 문구가 압력 셀이 변위 셀보다 잘다는 뜻인지 원문 확인이 필요하다.
