# S02 항등 사상

- 질문: 물리 knot + Greville 제어점 NurbsVolume에서 `GlobalCoordinates(ξ) == ξ`, 적분점 기하 `DeterminantOfJacobian == 1`? (Frame 회전 포함)
- 결과: 예
- 근거:
  - `pytest WHT_IGA/tests/kratos_spikes/test_s02_identity.py` 3/3 통과
  - 2×2×2셀 p=2, 셀 내부 임의 10점: `GlobalCoordinates` 최대 오차 4.440892098500626e-16 (허용 1e-14)
  - 8셀 전부 적분점 기하 detJ 편차 최대 1.1102230246251565e-15 (허용 1e-14)
  - Frame 회전(30°, 축 (1,1,1)): 위치 오차 3.3306690738754696e-16, detJ 편차 1.1102230246251565e-15
  - 주의: 회전 케이스에서 QP 생성 입력점은 파라미터 좌표 그대로(회전 전 Gauss점)를 넣어야 detJ=1. 물리 회전점을 넣으면 틀림(입력 규약 확인됨)
- 환경: Python 3.12.16, Kratos 10.4.3 (`E:\kratos-build\install`), 2026-11-14
- 결론과 영향: v2 §5.2.1 항등 사상 트릭 성립. 적분점 국소좌표=물리좌표, 가중치=물리 dV 그대로 사용 가능. R1 경로 전제 확보
- 재현: pytest WHT_IGA/tests/kratos_spikes/test_s02_identity.py
